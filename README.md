# Hashmedo Workflow Assessment

Describe an approval, handoff or exception process in Claude. The workflow assessment skill maps the current steps, identifies who decides, and suggests a change you can measure. It compares the workflow with Hashmedo’s public capabilities. Your team retains responsibility for decisions and for running the workflow.

Open the plugin in Claude, select its Connectors tab, and connect the bundled Hashmedo connector. It uses the public catalog without requiring a Hashmedo account.

Try a fictional workflow in a new conversation.

> Assess our equipment request process. A researcher submits a request, an assistant returns incomplete requests for correction, and a team lead approves or declines completed requests. Procurement handles approved requests. Show the current flow and suggest one improvement to test.

The optional viewer renders pasted Mermaid in your browser. Claude processes your workflow description. The Hashmedo catalog call accepts no inputs. Use fictional or redacted details when testing.
